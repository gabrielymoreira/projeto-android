# Projeto Android

Página web desenvolvida durante os estudos de HTML5 e CSS3 no Curso em Vídeo, com foco na construção de uma página informativa, organização de conteúdo e aplicação de técnicas de responsividade.

O projeto apresenta a história do mascote do Android, abordando suas primeiras versões e o surgimento do Bugdroid.

## Sobre o projeto
O objetivo deste projeto foi colocar em prática conceitos fundamentais de desenvolvimento Front-End, criando uma página estruturada semanticamente e adaptável a diferentes dispositivos.

Durante o desenvolvimento, foram explorados recursos de HTML e CSS para organização de textos, imagens, navegação e elementos visuais.

## Tecnologias Utilizadas
* HTML5
* CSS3
